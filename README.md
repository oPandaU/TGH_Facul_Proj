# The Gathering Hub (TGH)
> Sistema de reviews e gerenciamento de jogos desenvolvido em Java com Spring Boot.

# Sobre o Projeto
The Gathering Hub é uma plataforma web que permite aos usuários registrar, avaliar e gerenciar informações sobre jogos. O sistema oferece funcionalidades completas de CRUD para jogos, usuários, reviews e registro de jogos jogados.


### **Tecnologias Utilizadas**

- Java 21
- Spring Boot 4.0.0
- Spring Data JPA
- MySQL
- Thymeleaf
- Maven
- JUnit 5
- Mockito
 
# Funcionalidades

### Games

- ✅ Cadastro de jogos
- ✅ Listagem e busca de jogos
- ✅ Filtros por gênero, developer e nome
- ✅ Atualização e exclusão de jogos

### Usuários

- ✅ Cadastro de usuários
- ✅ Busca por ID e email
- ✅ Atualização de perfil
- ✅ Gerenciamento de conta

### Reviews

- ✅ Criação de avaliações (nota e comentário)
- ✅ Listagem por jogo e por usuário
- ✅ Cálculo de média de notas
- ✅ Edição e exclusão de reviews

### Jogos Jogados

- ✅ Registro de jogos jogados
- ✅ Histórico por usuário
- ✅ Verificação de jogo já registrado
